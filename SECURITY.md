# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.1.x   | Yes       |
| 1.0.x   | No        |

## Reporting a Vulnerability

Security issues should not be reported via public GitHub issues.

If you identify a security vulnerability in Lnastaqim:
1. Contact the maintainers directly or report through GitHub Security Advisories if enabled.
2. Include reproduction steps, platform details, OS version, and any relevant logs or proof of concept.

Receipt will be acknowledged within 48 hours, and patches will be deployed as soon as possible.
